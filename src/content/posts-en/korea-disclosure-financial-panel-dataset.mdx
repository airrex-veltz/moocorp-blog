We release in a single file the annual financial facts of Korea's disclosure-subject companies. The source is OpenDART (Financial Services Commission E-Disclosure System), and our work consists solely of **normalizing dispersed periodic report financial information, company by company, into one panel**.

The dataset spans fifteen columns: stock code, company name, fiscal year, consolidated/separate filing flag (`fs_div`), revenue, operating income, net income, total assets, total equity, total liabilities, operating cash flow, and four calculated ratios (debt-to-equity, ROE, ROA, operating cash flow-to-net income).

## Two Cautions When Reading

**Check `fs_div` first.** CFS denotes consolidated; OFS denotes separate. The same company's year-to-year basis sometimes mixes, so comparing revenue side-by-side without checking this column produces lies.

**`null` is not zero.** It means the disclosure omitted that field. For example, a bank's revenue cell is empty—financial statements lack the field—not that revenue is zero. Filling it with zero corrupts all aggregates.

## What's Not Included

**No opinions or forecasts.** No scores, rankings, or recommendations. This is by design, not laziness. The legal basis for how we handle data is "contains no opinions or forecasts." The generation script **enumerates** which fields are allowed and discards everything else, however much present in the source. A denylist approach risks silently passing new source fields through.

One boundary exclusion: internally we create mechanical notations like "loss years: 2024, 2025," facts in form but **which fact to highlight is editorial emphasis**, read as warning signal by readers. Facts alone don't qualify for inclusion. We excluded them.

**No largest shareholder data.** Writing a single disclosure's largest shareholder into that company's article is different from bundling thousands of names and ownership stakes into one machine-readable file for download. The individual disclosure articles retain it; this dataset alone omits it.

**Companies without financial statements are omitted.** Special acquisition purpose companies (SPACs) or unreporting firms (count above). Missing code doesn't denote financial condition.

## Usage Terms and Conditions

Attribution of source alone permits all use, including commercial. This is public data under Korea's "Public Data Provision and Use Activation Act," with no restrictions in the portal's terms.

Real-time query API is not provided. OpenDART's terms prohibit third parties using authentication keys, so relaying external requests via our key is impossible. What we can do is deliver processed output as static files—hence the links here point to files.
