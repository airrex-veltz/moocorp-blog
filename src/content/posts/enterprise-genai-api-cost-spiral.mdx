## 생성AI API 경쟁이 엔터프라이즈 소프트웨어 비용을 폭증시킨다

기업이 생성AI를 도입할 때마다 숨겨진 비용 폭탄을 맞고 있다. OpenAI, Google, Anthropic이 API 가격을 내리며 경쟁하지만, 기업의 총소유비용(TCO)은 악화되는 역설이 일어나고 있다.

## 구조: API 가격 경쟁 속 기업 비용은 왜 늘어나나

Salesforce의 **CRM**, Adobe의 **ADBE**, ServiceNow의 **NOW** 같은 엔터프라이즈 소프트웨어는 이미 기본 가입료로 수십~수백만 달러를 받는다. 여기에 생성AI 기능을 얹으면서 숨은 비용이 두 겹으로 쌓인다. 첫째, API 호출 비용이 매월 예측 불가능하게 변한다. 둘째, 기존 아키텍처에 생성AI를 통합하는 엔지니어링 비용이 추가된다.

## 왜 지금 기업의 생성AI 비용이 폭증하는가: 4가지 요인

**1. API 가격의 불확실성**: OpenAI 텍스트-다빈치는 2023년 입력 토큰 당 $0.02에서 현재 $0.50 수준으로 떨어졌지만, 기업은 사용량을 정확히 예측할 수 없다. 한 사용자가 생성AI 조회를 10번 하는지 100번 하는지에 따라 월 비용이 10배 이상 달라진다. 고정 예산 체계인 CIO 입장에서 이는 악몽이다.

**2. 마이그레이션 비용의 숨은 덫**: 기업이 OpenAI API에서 Anthropic이나 Google Gemini로 전환하려면 프롬프트 엔지니어링부터 전체 통합 재작업까지 해야 한다. 이는 수개월 개발팀 배치를 의미하고, 결국 기업은 한 공급업체에 묶인다. CRM 소프트웨어 자체는 이미 소수 거대 기업이 지배하는데, 생성AI API까지 추가되면서 선택지가 더 좁혀진다.

**3. 소프트웨어 벤더의 원가 전가**: Salesforce, Adobe, ServiceNow가 생성AI 기능을 기본 기능에 포함시키기 위해 막대한 개발 비용을 들인다. 이 비용의 일부는 가입료 인상, 일부는 API 메터링 요금으로 고객에게 전가된다. 각사는 "프리미엄 생성AI" 옵션을 따로 팔기 시작했고, 기업은 기본 라이센스에 생성AI 애드온을 구매해야 하는 이중 지출을 한다.

**4. 규모의 불경제**: 소규모 기업은 OpenAI API를 직접 쓸 때 토큰당 요금을 그대로 부담하지만, Salesforce처럼 대규모 기업은 OpenAI와 거래량 할인을 협상할 수 있다. 하지만 이 할인을 모든 고객에게 나누지 않으므로, 중소 사용자는 비용 부담이 더 크다. 동시에 API 가격이 떨어지는 속도가 벤더의 인상 속도보다 빠르면, 기업 고객은 가격 하락의 이득을 받지 못한다.

## 그래도 CRM, ADBE, NOW인 이유: 구조적 강점과 약점

**장점 — 규모의 이득**: Salesforce, Adobe, ServiceNow는 자체 생성AI 모델을 구축하거나 대규모 할인 협상으로 API 비용을 낮출 수 있다. 특히 이들은 고객 데이터를 소유하고 있어 미세조정(fine-tuning) 비용도 절약할 수 있다. 10년 고객 데이터로 학습한 모델은 Open AI의 범용 모델보다 훨씬 효율적이다.

**약점 — TCO 투명성 부족**: 가입료 + 사용료 + API 비용 + 통합 비용이 섞이면서 고객은 전체 비용을 파악하기 어렵다. 이는 기업 구매 결정의 지연과 경쟁사로의 이탈을 초래한다. 특히 중형 기업(종업원 500~2,000명)은 예산 당논이 빈번하다.

## 정리

생성AI는 이제 소프트웨어 기능이 아니라 비용 요소다. OpenAI와 Google의 API 가격 경쟁은 환상이고, 실제 기업의 부담은 늘고 있다. 향후 1~2년간 가장 주목할 지점은 Salesforce와 Adobe 같은 거대 벤더가 자체 생성AI 모델 투자를 얼마나 가속화하느냐, 그리고 중소 기업 고객에게 TCO 투명성을 얼마나 제공하느냐다.
